# Eliot PLOS Assets Guidelines

This directory houses static assets, vector graphics, icons, and typographic references for Eliot Personal Learning Operating System.

## Directory Layout
- `src/assets/icons/` — Vector graphics and SVG icons.
- `src/assets/images/` — Static imagery and illustration assets.
- `src/assets/styles/` — Global styling overrides and typography variables.

## Typography & Color Palette
- Primary Display: Inter / Plus Jakarta Sans
- Monospace Data / Kernel: JetBrains Mono / Fira Code
- Palette: Dark Slate (`#020617`), Slate (`#0f172a`), Indigo Accent (`#6366f1`), Emerald Status (`#10b981`), Sky Info (`#0ea5e9`).
