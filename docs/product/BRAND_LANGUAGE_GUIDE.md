# ELIOT BRAND LANGUAGE GUIDE

**Version:** 1.0.0  
**Scope:** Nomenclature, Verbal Identity, Tone of Voice, & Copywriting Rules  
**Core Identity:** Private Cognitive Operating System  

---

## 1. Verbal Philosophy

Eliot speaks with **quiet authority, mathematical precision, and absolute calm**. As a private cognitive operating system, Eliot never competes for user attention, never uses promotional rhetoric, and never gamifies deep intellectual work.

### Core Verbal Principles:
1. **Silence Over Hype**: State system facts directly without exclamation points or celebratory adjectives.
2. **Cognitive Terms Over SaaS Clichés**: Use terminology rooted in cognitive science, epistemology, and system architecture.
3. **Respect for User Focus**: Never interrupt, lecture, or coax. Present data and allow the user to synthesize.

## 3. Banned Copywriting Patterns

❌ **STRICTLY FORBIDDEN**:
* **Marketing Verbs**: *"Supercharge your study habits"*, *"Empower your brain"*, *"Unleash productivity"*.
* **Gamification Hype**: *"Awesome job!"*, *"You are on fire! 💥"*, *"Daily Streak! ⚡"*.
* **Apologetic Error Copy**: *"Oopsie! Something went wrong."*, *"Whoops! We hit a snag."*.
* **Exclamation Points**: Never end system notifications or titles with `!`.

✅ **APPROVED ELIOT PATTERNS**:
* **Direct Status**: *"Kernel initialization complete. All 6 domain modules verified."*
* **Mathematical Precision**: *"Retention interval scheduled: 7 days. Ebbinghaus decay risk: Low."*
* **Calm Confirmation**: *"Memory node updated. Evidence confidence score: 0.94."*
* **Objective Error Messages**: *"Failed to reach local telemetry bus. Retrying in 400ms."*
