# Typography Guide (TSA-1)

## Typographic Architecture

### 1. Font Pairings
* **Display & Headings**: *Plus Jakarta Sans* / *Syne* / *JetBrains Mono* (for technical headers).
* **Body Copy**: *Inter* / *Plus Jakarta Sans* (high legibility at 14px - 16px).
* **Code & Data**: *JetBrains Mono* (monospaced telemetry & entity IDs).

### 2. Type Scale (Step Ratio 1.125 - Major Second)
* **Caption / Label**: `11px` / `12px` (`line-height: 1.4`)
* **Body Standard**: `14px` / `16px` (`line-height: 1.5 - 1.6`)
* **Sub-heading**: `18px` (`line-height: 1.4`, `font-weight: 600`)
* **Heading (H2/H3)**: `22px` - `28px` (`line-height: 1.25`, `font-weight: 700`)
* **Display (H1)**: `32px` - `36px` (`line-height: 1.2`, `font-weight: 800`)

### 3. Execution Rules
* Minimum body copy font size: `14px`.
* Button/Pill text must sit on **ONE** line with `white-space: nowrap`.
* Line width constrained to `65ch` - `75ch` for long-form reading contexts.
