# Eliot PLOS — Focus Mode User Guide

## What is Focus Mode?

Focus Mode is an intentional, distraction-free learning environment activated automatically whenever you launch a Learning Session or Practice Drill in Eliot.

When Focus Mode is active, Eliot collapses extraneous interface elements (navigation bars, system status tickers, background notifications) to dedicate 100% of screen real estate and visual attention to your active learning material.

---

## Features & Controls

1. **Minimal Focus Bar**:
   - Located at the top of the viewport.
   - Shows your active mission objective, elapsed focus time, and session progress stage.
   - Includes a **Focus Lock** toggle button to lock working memory context.

2. **Expanded Workspace Surface**:
   - The main workspace expands to `max-w-6xl`, providing generous room for multi-panel viewports (learning sources, practice code editors, reflection pads, and evidence submission).

3. **Cognitive Silence**:
   - Telemetry tickers, status banners, and non-essential notifications are muted to eliminate peripheral visual noise.

4. **Instant Escape**:
   - Press the `Esc` key on your keyboard at any time to leave Focus Mode instantly and return to Mission Control.
   - Alternatively, click the **Exit Focus** button in the top right of the Focus Bar.
