# Eliot PLOS — Competitive Benchmark Analysis

## Comparative Matrix

| Product / Standard | Strengths | Weaknesses / Limitations | What Eliot Learns & Surpasses |
| :--- | :--- | :--- | :--- |
| **Linear** | Pristine typography, ultra-fast keyboard navigation, subtle borders, high visual discipline. | Limited to task tracking; no support for serif reading or multi-theme cognitive adaptation. | Eliot matches Linear's snappy keyboard efficiency while offering specialized reading and technical themes (*Scholar*, *Architect*). |
| **Notion** | Flexible block canvas, approachable light layout. | High visual clutter; generic dark mode; poor focus mode isolation; sluggish performance on heavy pages. | Eliot provides superior cognitive focus isolation, instant theme switching, and zero visual noise during learning sessions. |
| **Raycast** | Best-in-class Command Deck (`⌘K`); keyboard-first interaction; clean dark surfaces. | Focused entirely on quick utility triggers; not designed for long-form absorption or knowledge graphs. | Eliot incorporates Raycast's instant command palette accessibility into a full learning OS. |
| **Cursor** | Dense developer workspace; excellent terminal and code panel hierarchy. | High density creates visual fatigue during non-coding conceptual study. | Eliot balances technical precision (*Architect* mode) with warm absorption (*Scholar* mode). |
| **Obsidian** | Local markdown storage; graph view visualization. | Fragmented community themes; inconsistent spacing; lack of curated typography systems. | Eliot provides a unified, mathematically disciplined design token system with zero configuration burden. |
| **Apple HIG** | Subtle translucency, fluid spring physics, accessible contrast. | Generic glassmorphism can cause legibility issues on complex backgrounds. | Eliot adopts clean spatial hierarchy without relying on legibility-impairing background blurs. |
| **Material 3** | Dynamic color extraction, accessible contrast tokens. | Oversized rounded shapes and whimsical aesthetics feel inappropriate for serious academic research. | Eliot uses disciplined, task-appropriate radii (`0px` in Scholar, `4px` in Architect, `8px` in Operator). |
| **Fluent 2** | Strong grid alignment, clear acrylic depth layering. | Heavy visual density; complex nested panel borders. | Eliot flattens depth and uses high-contrast typography hierarchy over heavy borders. |
