# ELIOT EMOTIONAL FLOW REPORT

**Version:** 1.0.0  
**Scope:** Emotional Curve Mapping Across the Learning Lifecycle  

---

## 1. Emotional Journey Curve

Eliot's experience is intentionally engineered to guide the user through a quiet, disciplined emotional trajectory:

```
Curiosity (Boot) ──> Confidence (Mission Control) ──> Focus (Learning Session)
                                                             │
Readiness (Return) <── Accomplishment (Evidence) <── Reflection (Review)
```

---

## 2. Emotional Target Matrix

| Stage | Target Emotion | Undesired Emotion (Forbidden) | Design Mechanism Preserving Emotional Target |
| :--- | :--- | :--- | :--- |
| **Boot Experience** | Curiosity & Calm | Confusion or Frustration | Zero-exception step verification progress with collapsible diagnostics. |
| **Mission Control** | Confidence & Direction | Overwhelmed or Anxious | Single dominant primary action button with "Why This Matters" cognitive rationale. |
| **Learning Session** | Deep Focus & Clarity | Boredom or Distraction | Clean typographic layout, high contrast, zero floating notifications. |
| **Practice Workspace**| Active Engagement | Frustration or Fear of Failure | Constructive feedback cards without punitive scoring. |
| **Session Reflection**| Quiet Reflection | Rush or Surface Completion | Metacognitive prompts encouraging self-assessment. |
| **Evidence Submission**| Sense of Solid Grounding| Doubt or Vagueness | Clear evidence confidence scores tied to sources. |
| **Return to Control** | Quiet Accomplishment & Readiness| Exhaustion or Overstimulation | Updated mastery indices in Layer 5 without noisy celebratory confetti. |

---

## 3. Emotional Safeguards

1. **Anti-Anxiety Safeguard**: No countdown timers that create artificial panic during practice sessions.
2. **Anti-Shame Safeguard**: No "streak broken" red warning banners if a user skips a day; memory decay is presented objectively as a mathematical retrieval schedule.
3. **Calm Completion**: Replaces loud badges and fireworks with quiet, dignified state updates.
