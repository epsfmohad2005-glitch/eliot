# Eliot PLOS — Theme Showcase Guide

## Quick Start: Accessing the Theme Engine & Showcase

1. **Header Bar Theme Selector**:
   - In the top right header bar of the application, click the **Palette icon** button showing the active theme name (`Operator`, `Scholar`, `Architect`, `Nocturne`, `Aurora`, or `Minimal`).
   - Select any theme from the dropdown menu to instantly re-theme the entire application shell and all workspaces.

2. **FCS-1 Component Showcase View**:
   - Click the **FCS-1 Showcase** button in the header bar or navigate via Command Palette (`⌘K`).
   - The Component Showcase provides an isolated environment where all 6 themes can be tested against every FCS-1 component primitive (Buttons, Inputs, Navigation, Banners, Badges, Modals, Knowledge Nodes, Memory Timeline cards).

3. **RTL Direction Toggle**:
   - Click the **LTR / RTL** toggle button in the Theme Engine dropdown menu or in the FCS-1 Showcase header to view layout mirroring in Right-To-Left direction mode.

## The 6 Approved Themes Showcase Overview

### 1. Operator (Tactical Command)
- **Palette**: Charcoal `#0A0A0A` canvas, Focus Mint `#00FFC2` accent, slate surface containers.
- **Ideal For**: Deep focus sessions, code editing, data inspection, low-light environments.

### 2. Scholar (Paper Reading)
- **Palette**: Paper Cream `#F5F2ED` background, Ink `#1A1A1A` body text, Scholarly Oxblood `#800020` accent.
- **Typography**: Newsreader serif for deep reading absorption.
- **Radii**: Sharp 0px rectangular edges mimicking bound paper.

### 3. Architect (Blueprint Technical)
- **Palette**: Blueprint Navy `#101827`, Electric Sky `#38BDF8`, transparent grid background lines.
- **Typography**: IBM Plex Mono technical monospaced typeface.
- **Radii**: Clean 4px technical borders.

### 4. Nocturne (Velvet Midnight)
- **Palette**: Midnight `#05050A` canvas, Amethyst Purple `#A855F7` accent, soft lavender text `#F3F0FF`.
- **Ideal For**: Nighttime study and calm reflection.

### 5. Aurora (Nordic Teal & Gold)
- **Palette**: Deep Teal `#031B1B` canvas, Northern Cyan `#06B6D4`, Frost Gold highlights `#F59E0B`.
- **Ideal For**: High-contrast analytical study.

### 6. Minimal (Bauhaus Stark Monochrome)
- **Palette**: Graphite `#121212` canvas, Chalk `#F8FAFC`, Pure White `#FFFFFF` signal accents.
- **Ideal For**: High contrast, distraction-free stark minimalist study.
