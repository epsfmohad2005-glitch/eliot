# Iconography System (TSA-1)

## Icon Standards

### 1. Library Selection
* All iconography is strictly standardized on **`lucide-react`**.
* Direct custom SVG strings or third-party icon packages are prohibited.

### 2. Sizing Matrix
* **Micro / Inline**: `14px x 14px` (`stroke-width: 2.0`)
* **Standard Control**: `16px x 16px` (`stroke-width: 1.75`)
* **Section / Header**: `20px x 20px` (`stroke-width: 1.5`)
* **Hero Feature**: `24px x 24px` (`stroke-width: 1.5`)

### 3. Usage Rules
* Icons must align with surrounding text baseline.
* Decorative background icon bubbles must maintain a $1:1$ aspect ratio container.
