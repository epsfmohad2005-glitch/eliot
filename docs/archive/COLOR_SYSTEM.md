# Color System (TSA-1)

## Palette Architecture & Luminance Constraints

### Dark Operational Mode
* **Canvas (`--bg-canvas`)**: `#090d16` (Cool slate black, HSB saturation $<5\%$)
* **Surface Card (`--surface-card`)**: `#111827` (Deep slate)
* **Surface Low (`--surface-low`)**: `#1f2937`
* **Border Color (`--border-color`)**: `#374151` (1px subtle separation)
* **Primary Text (`--text-primary`)**: `#f9fafb`
* **Secondary Text (`--text-secondary`)**: `#9ca3af`

### Light Operational Mode
* **Canvas (`--bg-canvas`)**: `#f8fafc` (Slate white)
* **Surface Card (`--surface-card`)**: `#ffffff` (Pure white)
* **Surface Low (`--surface-low`)**: `#f1f5f9`
* **Border Color (`--border-color`)**: `#e2e8f0`
* **Primary Text (`--text-primary`)**: `#0f172a`
* **Secondary Text (`--text-secondary`)**: `#475569`

### Accent Domain Colors
* **Signal / Primary**: Indigo `#6366f1` / `#4f46e5`
* **Telemetry / Success**: Emerald `#10b981`
* **Alert / Warning**: Amber `#f59e0b`
* **Error**: Rose `#f43f5e`
