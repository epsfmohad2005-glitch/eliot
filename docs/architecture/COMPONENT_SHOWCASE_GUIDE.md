# ELIOT COMPONENT SHOWCASE GUIDE (FCS-1)

**Version:** 1.0.0  
**Environment:** Isolated Visual Testing Environment  

---

## 1. Accessing the Component Showcase

The **Component Showcase** is accessible directly within the Eliot application:
1. Click the **"FCS-1 Showcase"** button located in the top Header Bar next to "Inspect Architecture".
2. Or navigate directly to the `showcase` route in the application shell.

---

## 2. Interactive Testing Capabilities

The showcase provides real-time visual testing across all components and states:

### 2.1 Theme Switcher
Toggle between all three visual identities instantly:
* **Operator Theme**: Technical obsidian dark canvas with Focus Mint accents.
* **Scholar Theme**: Paper Cream reading layout with Scholarly Oxblood accents and sharp rectangular radii.
* **Architect Theme**: Blueprint Dark Blue layout with grid background.

### 2.2 RTL / LTR Direction Toggle
Switch between English (Left-to-Right) and Arabic (Right-to-Left) layouts to audit text alignment, mirror icons, and logical spacing.

### 2.3 Interactive Category Filtering
Filter components by category tabs:
1. **All Components**: Complete gallery overview.
2. **Buttons & Inputs**: Button variants, search inputs, password toggles, number inputs.
3. **Navigation & Containers**: Nav items, sidebars, header actions, command palette triggers, panels.
4. **Feedback & Selection**: Alerts, banners, progress bars, step wizards, toggles, checkboxes.
5. **Knowledge Primitives**: Knowledge nodes, memory cards, evidence badges, focus meters, mission cards.
6. **Dialogs & Overlays**: Modals, confirmation dialogs, command deck (`⌘K`), side sheets, context menus (`Right Click`).
